# Module: Practice Engine

## 模式动态调度表
AI 依据原子知识点属性自主匹配，每次进入 PRACTICE 必须声明采用的模式：

1. **BUILD (独立构建)**：给出任务规格，用户从零手写代码或配置。适用于基础语法与 API。
2. **DEBUG (隐蔽排错)**：提供一段包含边界缺陷的代码，用户定位根因并修复。适用于高频坑点。
3. **MODIFY (重构加固)**：提供一段运行正常但设计不佳（如类型宽松、有副作用）的代码，要求用户重构。适用于进阶规范。
4. **PREDICT (执行推演)**：给出反直觉或复杂执行序用例，要求推演打印结果并解释执行上下文。适用于机制原理（如事件循环、作用域）。
5. **EXPLAIN (心智拆解)**：要求用文字拆解系统流程时序。适用于架构设计与网络协议。
6. **DESIGN (方案设计)**：给定受限业务场景，设计数据结构与接口类型定义。适用于大型模块抽象。
