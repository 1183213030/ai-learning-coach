## 四、提案里必须驳回的两条

### 1. "16 周通用前端课程" —— 与学习者目标不匹配

提案的课程顺序是通用的现代前端：JS → CSS → Vue → 工程化。但：

- 学习者时间预算是 **45 分钟/天**（提案假设 2–3 小时/天，差 5 倍，同一体系需 85–100 周）；
- 目标 JD 要的是 **jQuery / 浏览器兼容 / 页面静态化**，提案一个字没提；
- JS 语法与原理学习者已 L2 满级，前 8 周是空转。

**处置：课程顺序按 JD 重排，不走提案的 16 周顺序。** 详见《学习计划-天正信息前端JD.md》。

### 2. 建 `tutor/` 目录 —— 与 `references/` 语义重叠

提案要 5 个 tutor 文件，仓库 `references/` 里已有对应 5 份规范，且被 `SKILL.md` 与 `evals/` 引用。再建一套会导致两份规则互相打架、状态失真。

**处置：不建 `tutor/`；只补一份 `references/mode-router.md`（五种模式何时切换的判定表），指向已有 5 份文件。**
