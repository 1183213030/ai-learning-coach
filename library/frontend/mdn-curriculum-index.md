# MDN Web Development Curriculum & Standards Index

> **资料标识**：`src-mdn-curriculum`  
> **级别**：`S0` (Official Curriculum & Living Standards)  
> **根地址**：[https://developer.mozilla.org/en-US/docs/Learn_web_development](https://developer.mozilla.org/en-US/docs/Learn_web_development)  
> **角色**：主线教学大纲、Web 平台标准能力与进阶路径映射

---

## 模块结构与精准映射

### 1. 核心前置与入门 (Getting Started with the Web)
- **大纲路径**：`Getting_started_with_the_web`
- **对应能力**：Web 运行机制、客户端-服务端架构基础、HTML/CSS/JS 协同体系
- **标准链接**：
  - Web 基础入门: [Getting started with the web](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started_with_the_web)
  - 核心文件处理与发布: [Dealing with files](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started_with_the_web/Dealing_with_files)

### 2. HTML — 结构化语义基石 (Structuring the Web)
- **大纲路径**：`Core/Structuring_content`
- **对应能力**：语义化标签树、表单验证协议、无障碍访问 (a11y)
- **标准链接**：
  - HTML 基础入门: [Introduction to HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content)
  - HTML 多媒体与嵌入: [Multimedia and embedding](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Multimedia_and_embedding)
  - HTML 表单与数据校验: [HTML forms](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms)

### 3. CSS — 渲染与样式布局 (Styling the Web)
- **大纲路径**：`Core/Styling_basics` & `Core/Layout`
- **对应能力**：盒模型、选择器权重 (Specificity)、层叠与继承 (Cascade)、Flexbox、Grid 布局
- **标准链接**：
  - CSS 第一步: [CSS first steps](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics)
  - 盒模型详解: [The box model](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model)
  - 层叠与选择器层级: [Cascade, specificity, and inheritance](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Handling_conflicts)
  - 现代布局方案 (Flex/Grid): [CSS layout](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Layout)

### 4. JavaScript — 动态客户端交互 (Dynamic Client-Side Scripting)
- **大纲路径**：`Core/Scripting`
- **对应能力**：原始类型、作用域与闭包、异步流与事件循环、DOM 节点树操作
- **标准链接**：
  - JavaScript 入门第一步: [JavaScript first steps](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting)
  - JS 核心构建块: [JavaScript building blocks](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Conditionals)
  - 面向对象与原型链: [Introducing JavaScript objects](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Advanced_JavaScript_objects)
  - 异步编程全景 (Async/Await, Promise): [Asynchronous JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS)
  - 客户端 Web API 与 DOM 操作: [Client-side web APIs](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Client-side_APIs)

### 5. 进阶工程与性能规范 (Advanced Topics)
- **对应能力**：Web 性能度量、客户端离线存储、网络安全基础
- **标准链接**：
  - Web 性能与优化: [Web performance](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Performance)
  - 客户端存储与离线应用: [Client-side storage](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Client-side_APIs/Client-side_storage)
  - Web 安全最佳实践: [Web security](https://developer.mozilla.org/en-US/docs/Web/Security)
