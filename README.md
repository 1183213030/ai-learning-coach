## 为什么你需要这个工具？

平时学编程或新技术，我们几乎都会经历以下三种让人绝望的困境：

1. **“眼睛会了，手不会”**：看视频教程或技术博客时连连点头，觉得“太简单了”；一旦关掉教程在白纸上自己敲代码，脑子一片空白，不知道第一行该写什么。
2. **“普通 AI 像个代写保姆”**：遇到不懂的去问 ChatGPT，它哗啦一下把几百行现成代码和专业术语全倒给你。你顺手复制粘贴解决了眼前的问题，但关掉聊天窗口，你的大脑依旧什么都没学会。
3. **“学得东拼西凑，像到处捡碎拼图”**：今天在网上看了一篇博客，明天看了一个短视频，学的全是孤立的碎片点。学了几个月，依然连不起一整套完整的前端或工程知识体系。

**AI Learning Coach** 就是为了彻底改变这一切而设计的。它不是替你写作业的工具，而是**专为你服务的专属技术私教**：它不直接给你喂现成代码，而是用生动的比喻、对比实验和闭卷考核，确保技能真真正正长在你自己的身上。

## 它是怎么把一个初学者真正教会的？

### 1. 三维完整性：知道了 ≠ 教完了 ≠ 学会了
市面上很多学习工具最大的问题是把“把概念念了一遍”当成“学生已经会了”。本教练在底层严格追踪三个独立维度：
- **知识边界完整 (Knowledge)**：在后台依据官方权威标准把每一个概念的所有行为边界、特殊坑点盘点清楚，绝不遗漏；
- **教学实施完整 (Teaching)**：哪怕后台知道 10 个维度，面对初学者单次对话只推进 2 个小点，用单变量实验带你观察，绝不信息过载；
- **独立能力完整 (Capability)**：只有在你脱离 AI 帮助、闭卷答对且能迁移到真实工程场景时，才记录为“真正掌握”。

### 2. 先画“藏宝图”，一环扣一环通关，绝不让你乱学
无论你告诉它“我想学做网页”还是“我想学前端开发”，它第一件事不是机械地背课本，而是在幕后为你生成一张清晰的**技能树地图**：
- 什么是第一步必须打好的地基（比如最基础的网页骨架）；
- 什么是第二步、第三步；
- 终点在哪里，各个知识点是怎么连在一起的。
前一步的核心机制没掌握稳，它绝对不会盲目拔苗助长推进到下一章，让你学得心里极其踏实。

### 3. 单变量对比实验：改变一个参数，亲眼看结果突变
很多教程只会讲“这个东西是干嘛的”，而好老师会带你做实验。
比如学数组查找，它不会逼你死记硬背定义，而是像做科学实验一样，**每次只改变一个变量**，带你观察现象：
- `[1, 2, 3]` 里面找 `2` -> 找到（正常）
- `[1, 2, 3]` 里面找 `4` -> 找不到（值变了）
- `['1', '2', '3']` 里面找 `1` -> 找不到（类型变了，带引号的和数字不同）
- `[[1]]` 里面找 `[1]` -> 找不到（对象引用身份不同，揭开底层数据比较的秘密）
通过亲眼看着结果一步一步变化，你不是在背枯燥的语法，而是在脑海中自然建立了对代码规律的物理直觉。

### 4. 反例冲击：打破自以为是的“假懂”
初学者最怕误以为自己全懂了。
这个教练特别擅长出一些**“看起来完全对、一运行立刻报错”的反例**：
- 比如检测一段话里有没有 `"admin"` 这个单词；
- 它会给你看 `"你好，admin"`（通过）和 `"你好，admmmmmin"`（失败！）；
- 然后反问你：“为什么后者里面明明包含了 a、d、m、i、n 所有字母，电脑却判定不通过？”
当你自己恍然大悟回答出“因为字母必须连在一起不能断开”时，这个知识点就彻底刻进你的骨子里了。

### 5. 闭卷检验：嘴上说“我懂了”在它这不算数
普通的辅导最喜欢问“你听懂了吗？”，大家习惯性地回一句“懂了”，就以为自己学会了。
这个私教有严格的底线：**教归教，考归考**。
在真正考核你时，它会关掉所有提示和代码参考，让你像闭卷考试一样独立推导或手写。只有你脱离了 AI 也能真正写出来，它才会放心在你的能力档案里记上一笔“真正独立掌握”。

### 6. 懂你的时间与疲惫，现实生活永远优先
真实人类不是机器，不可能每天都能坐下来学 2 小时：
- 如果你今天加班到深夜，告诉它：*“今天太累了，只有 10 分钟”*；
- 它绝不强塞新课程，而是挑出你昨天的一个小盲区，用 5 分钟带你做个微型温习，搞定立刻放你休息；
- 如果你工作中突然碰到了真实 Bug，告诉它：*“先不学教程了，我页面卡死了帮我看看”*，它会立刻暂停主线课程，就地取材帮你排错，并从 Bug 里把技术原理教会你。

## 怎么使用？（你只需要说人话）

你不需要记住任何斜杠命令或技术缩写，直接像发微信一样跟它说话即可：

### 场景 A：从零开始学一个全新领域
> **你**：“我想系统学前端开发，但我是一个初学者，几乎完全不懂。”
> 
> **教练表现**：绝不抛出吓人的术语大纲。先出 1~2 个最简单的生活小观察题摸底你的基础，然后从最核心的直觉概念一步步带你起步。

### 场景 B：接续昨天进度
> **你**：“继续昨天的学习。”
> 
> **教练表现**：不问废话，直接调取昨天学完的进度和待攻克的难点，告诉你今天接着练什么。

### 场景 C：真的没听懂，要求换方式
> **你**：“你刚才讲的那个闭包太抽象了，我完全没懂，换个生活比喻讲讲。”
> 
> **教练表现**：立刻放弃专业术语，改用生活中的“酒店钥匙与保险箱”或“随身背包”比喻，把复杂的内存留存概念变成具象画面。

### 场景 D：时间有限，简单学习
> **你**：“今天赶需求加班，只有 15 分钟，不想看长篇大论，简单学点。”
> 
> **教练表现**：立刻切断新课推进，只拿昨天做错的一个边界值，用 3 分钟带你做道选择题，做完即刻收工。

### 场景 E：自我检验，绝不作弊
> **你**：“考考我刚才学的，但不要给我任何提示。”
> 
> **教练表现**：进入完全闭卷模式，隐去所有前面讲过的示例，出 1~2 道干净的新题目让你独立作答，据此记录真实水平。

### 场景 F：现实工作 Bug 打断
> **你**：“先别管教材了，我项目里页面报了跨域错误，帮我看看为什么。”
> 
> **教练表现**：冻结教材进度，全力帮你诊断浏览器的同源策略与后端配置，修完 Bug 顺便沉淀技术原理，绝不强行拉你回书本。

## 保姆级安装与部署指南

### 方式一：在 Google Antigravity 中使用（推荐 / 零配置）
本仓库已经完全原生配置好。如果你在 Antigravity 环境下：
1. 打开当前工作区；
2. 在对话框中直接输入任意你想学习的内容（例如：*“我想系统学习前端开发”*）；
3. 系统自动激活，即刻开启教学。

### 方式二：在 Claude Code 中使用（全平台通用）
如果你使用 Anthropic 的 Claude Code 终端助手：

**1. 全局安装（推荐，所有项目都能直接用）：**
```bash
npx skills add https://github.com/1183213030/ai-learning-coach.git --skill ai-learning-coach --global --agent claude-code
```

**2. 单项目安装（仅在当前工程目录生效）：**
```bash
npx skills add https://github.com/1183213030/ai-learning-coach.git --skill ai-learning-coach --agent claude-code
```
安装完成后，在 Claude Code 中像平常一样直接输入学习需求即可。

### 方式三：在 OpenAI Codex / 其他终端 Agent 中使用
```bash
npx skills add https://github.com/1183213030/ai-learning-coach.git --skill ai-learning-coach --global --agent codex
```

### 进阶用法：放入自己的电子书 / 笔记作为主干教材 (Local Library)
如果你手里已经有了很好的前端教程、PDF 电子书或自己的 Markdown 笔记，希望 AI 按照你的书来教：
1. 把你的文件直接拷贝到本项目的 `library/` 目录下（例如放入 `library/frontend/` 文件夹下）；
2. 随后直接对 AI 说：
   > *“用我本地 library 里的前端教材教我”*
3. AI 会自动优先阅读你的本地教材，提取章节脉络，并以此为主线展开教学，绝不会在网上胡乱搜索冲突的资料。

如果你是开发者，想了解系统内部是怎么组织的：

```text
ai-learning-coach/
├── SKILL.md                          # 系统最高调度法典与仲裁协议
├── README.md                         # 本文档 (大白话中文详细使用指南)
├── README_en.md                      # English Documentation
│
├── knowledge/                        # 动态知识库 (记录每个知识点的正例、反例、边界与避坑点)
│   ├── frontend/javascript/          # JavaScript 闭包、作用域、宽松比较、数组检索等
│   └── software-testing/             # 测试用例设计、边界分析等
│
├── library/                          # 本地教材库 (支持放入自己的 Markdown/书籍作为教材)
│   ├── frontend/                     # 前端体系教材
│   └── software-testing/             # 软件测试教材
│
├── references/                       # 核心教学与考核规范
│   ├── concept-boundary-engine.md    # [核心] 单变量受控实验与反例教学法典
│   ├── teaching-protocol.md          # 老师人格、生活比喻突变与微型动作探针
│   ├── curriculum-engine.md          # 现实生活优先原则与技能树动态规划

│   ├── local-library.md              # 本地教材逆向解析协议
│   ├── knowledge-discovery.md        # 官方权威规范溯源分级
│   ├── evidence-model.md             # 独立完成能力评估底账标准
│   └── review-system.md              # 艾宾浩斯防遗忘与动态复习算法
│
└── templates/                        # 状态持久化契约模板 (记录真实能力底账，绝不造假)
    ├── concept-expansion.yaml        # 概念完整行为空间展开模板
    ├── source-manifest.yaml          # 权威资料引用清单
    ├── roadmap.yaml                  # 技能树前置依赖图谱
    ├── learner-profile.md            # 个人能力基线与盲区档案
    └── evidence.yaml                 # 独立掌握的客观证据记录本
```
